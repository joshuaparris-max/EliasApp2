# EliasApp Media

Put child-safe, parent-reviewed media files here.

Suggested folders:

- `/public/media/images`
- `/public/media/videos`
- `/public/media/sounds`

Example paths used by the app:

- `/media/images/garbage-front-loader.jpg`
- `/media/images/excavator.jpg`
- `/media/videos/my-safe-video.mp4`
- `/media/sounds/soft-horn.mp3`

If an image is missing, EliasApp shows a large friendly emoji placeholder instead.
